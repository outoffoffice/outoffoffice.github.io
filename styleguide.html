03 — Buttons / CTA
Zustände + magnetischer Hover

Alle CTA-Pills (.cta, .next a, .copy-btn) teilen sich border-radius:999px, 1px --ink-Rahmen und denselben Hover: Hintergrund → --ink, Textfarbe → --paper.

standard
hover (fixiert zur Ansicht)
magnetischer effekt — live testen (Maus in die Box bewegen)
radius 85px · max. 12px Versatz 
function applyMagnetic(el, radius, maxOffset) {
  document.addEventListener('mousemove', (e) => {
    const rect = el.getBoundingClientRect();
    const cx = rect.left + rect.width / 2;
    const cy = rect.top + rect.height / 2;
    const dx = e.clientX - cx;
    const dy = e.clientY - cy;
    const dist = Math.hypot(dx, dy);
    if (dist < radius) {
      const pull = (1 - dist / radius) * maxOffset;
      const angle = Math.atan2(dy, dx);
      el.style.transform = `translate(${(Math.cos(angle) * pull).toFixed(2)}px, ${(Math.sin(angle) * pull).toFixed(2)}px)`;
    } else {
      el.style.transform = '';
    }
  });
}
// Buttons: radius 85, maxOffset 12 · Bilder/Thumbnails: radius 85, maxOffset 6–7
// CSS-Transition auf dem Element: transform 0.15s ease-out
