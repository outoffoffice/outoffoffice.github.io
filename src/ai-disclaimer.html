How this site was made

idea

Concept & design

The concept and the layout: a one-pager on a fixed grid, with project pages that slide in. I had it in my head before a single line of code existed. The visual direction, typography and colour, and which projects are shown and in what order, are mine too.

words

Texts

I wrote every text on this site myself. Claude read them afterwards as a proofreader: it pointed out typos, clumsy sentences and unclear passages, and sometimes suggested a different wording. What it says and how it sounds is mine.

code

Built with Claude Code

I used Claude Code to turn the idea into a working site: page structure, Eleventy templates, CSS and JavaScript, image compression and the build setup. I described what I wanted, checked the result in the browser and changed it until it matched what I had in mind.

projects

In my work

In my design work, AI is a tool for building and refining, not a replacement for ideas. Where a project used AI, its case study says so and explains how.
